# 権限マトリクス

## 1. 本書の目的

本書は、本システムにおけるユーザーごとの操作権限を整理する。

各機能について、どの利用者がどの操作を実行できるか、および実行時の条件を定義する。

## 2. 対象ロール

本システムでは以下のロールを定義する

| ロール | 概要 |
| --- | --- |
| 一般メンバー | - |
| プロジェクト管理者 | - |
| システム管理者 | - |

## 4. 条件付き権限
### AUTH-001 プロジェクト閲覧（一般メンバー、プロジェクト管理者）
- 一般メンバーおよびプロジェクト管理者は自身がプロジェクトメンバーであるプロジェクトのみ閲覧可能。

### AUTH-002
- プロジェクトメンバーを除外できるのは当該プロジェクトメンバーに未完了タスクが存在しない場合のみ。

### AUTH-003
- 一般メンバーが編集できるタスクは自身が担当するタスクであり、かつ許可された範囲の情報のみに限られる。

### AUTH-004
- 一般メンバーがタスクの担当者である場合のみ作業開始が可能。
- システム管理者が作業開始を実行するには、担当者が設定されていることが必要。

### AUTH-005
- 一般メンバーがレビュー依頼を実行可能なのはタスクの担当者である場合のみ。
- システム管理者がレビュー依頼を実行するには、担当者が設定されていることが必要。

### AUTH-006
- 一般メンバーがレビューを実行可能なのはレビュアーである場合のみ。
- システム管理者がレビューを実行可能なのはレビュアーが設定されていることが必要。

### AUTH-007
- 一般メンバーが承認・差し戻しを実行可能なのはレビュアーである場合のみ。

### AUTH-008
- 利用停止の対象となるユーザーが未完了タスクの担当者・レビュアー、
  もしくは唯一のプロジェクト管理者である場合は、利用停止にできない
