# 権限マトリクス

## 1. 本書の目的

本書は、本システムにおけるユーザーごとの操作権限を整理する。

各機能について、どの利用者がどの操作を実行できるか、および実行時の条件を定義する。

## 2. 対象ロール

本システムでは以下のロールを定義する

| ロール | 概要 |
| --- | --- |
| 一般メンバー | - |
| プロジェクト管理者 | - |
| システム管理者 | - |

## 3. 権限マトリクス

| 操作 | 一般メンバー | プロジェクト管理者 | システム管理者 | 条件・備考 |
|---|---|---|---|---|
| プロジェクト閲覧 | △ | △ | ○ | △: AUTH-001参照 |
| プロジェクト作成 | × | × | ○ | - |
| プロジェクト編集 | × | ○ | ○ | - |
| メンバー追加・除外 | × | △ | △ | △: AUTH-002参照 |
| タスク作成 | × | ○ | ○ | - |
| タスク編集 | △ | ○ | ○ | △: AUTH-003参照 |
| 作業開始 | - | - | - | - |
| レビュー依頼 | - | - | - | - |
| レビュー | - | - | - | - |
| 承認・差し戻し | - | - | - | - |
| タスク無効化 | - | - | - | - |
| 再オープン | - | - | - | - |
| コメント投稿・編集・削除 | - | - | - | - |
| ユーザー管理 | - | - | - | - |

## 4. 条件付き権限
### AUTH-001 プロジェクト閲覧（一般メンバー、プロジェクト管理者）
- 一般メンバーおよびプロジェクト管理者は自身がプロジェクトメンバーであるプロジェクトのみ閲覧可能。

### AUTH-002
- プロジェクトメンバーを除外できるのは当該プロジェクトメンバーに未完了タスクが存在しない場合のみ。
