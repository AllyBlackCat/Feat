# 権限マトリクス

## 1. 本書の目的

本書は、本システムにおけるユーザーごとの操作権限を整理する。

各機能について、どの利用者がどの操作を実行できるか、および実行時の条件を定義する。

## 2. 対象ロール

本システムでは以下のロールを定義する

| ロール | 概要 |
| --- | --- |
| 一般メンバー | - |
| プロジェクト管理者 | - |
| システム管理者 | - |

## 3. 権限マトリクス

○：当該ロールに操作権限がある
△：本人・担当者・指定レビュアー等の権限上の条件を満たす場合のみ操作可能
×：当該ロールに操作権限がない

なお、○または△の場合でも、状態遷移条件および業務ルールによる制約を受ける。

| 操作 | 一般メンバー | プロジェクト管理者 | システム管理者 | 条件・備考 |
|---|---|---|---|---|
| 参加プロジェクト閲覧 | ○ | ○ | ○ | - |
| 全プロジェクト閲覧 | × | × | ○ | - |
| プロジェクト作成 | × | × | ○ | - |
| プロジェクト編集 | × | ○ | ○ | - |
| メンバー追加 | × | ○ | ○ | 除外時はBR-011に従う |
| メンバー除外 | × | ○ | ○ | 除外時はBR-011に従う |
| タスク作成 | × | ○ | ○ | - |
| タスク編集 | △ | ○ | ○ | △: AUTH-003参照 |
| 作業開始 | △ | △ | ○ | △: AUTH-004参照 |
| レビュー依頼 | △ | △ | ○ | △: AUTH-005参照 |
| レビュー | △ | △ | ○ | △: AUTH-006参照 |
| 承認・差し戻し | △ | △ | ○ | △: AUTH-007参照 |
| タスク無効化 | × | ○ | ○ | - |
| 再オープン | × | ○ | ○ | - |
| コメント投稿 | ○ | ○ | ○ | - |
| コメント編集 | △ | △ | △ | △: AUTH-009 参照 |
| コメント削除 | △ | △ | ○ | △: AUTH-010 参照  |
| ユーザー管理 | × | × | ○ | - |

## 4. 条件付き権限

### AUTH-003
- 一般メンバーが編集できるタスクは自身が担当するタスクについて、タイトルおよび内容のみ変更できる。

### AUTH-004
- 一般メンバーがタスクの担当者である場合のみ作業開始が可能。
- プロジェクト管理者がタスクの担当者である場合のみ作業開始が可能。
- システム管理者が作業開始を実行するには、担当者が設定されていることが必要。

### AUTH-005
- 一般メンバーがレビュー依頼を実行可能なのはタスクの担当者である場合のみ。
- プロジェクト管理者がレビュー依頼を実行可能なのはタスクの担当者である場合のみ。
- システム管理者がレビュー依頼を実行するには、担当者が設定されていることが必要。

### AUTH-006
- 一般メンバーがレビューを実行可能なのはレビュアーである場合のみ。
- プロジェクト管理者がレビューを実行可能なのはレビュアーである場合のみ。
- システム管理者がレビューを実行可能なのはレビュアーが設定されていることが必要。

### AUTH-007
- 一般メンバーが承認・差し戻しを実行可能なのはレビュアーである場合のみ。
- プロジェクト管理者が承認・差し戻しを実行可能なのはレビュアーである場合のみ。

### AUTH-009
- 自身の投稿のみ

### AUTH-010
- 自身の投稿のみ
